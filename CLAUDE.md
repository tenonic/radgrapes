# CLAUDE.md

This repo holds simple games built from the user's instructions. Each game has its own folder:

- [castle-game/](castle-game/): the castle game (the first game).

In each game folder:

- The game rules and requirements are in that folder's `INSTRUCTIONS.md`. Read it before making changes to that game and follow it.
- When the user gives a new instruction for a game, add it to that game's `INSTRUCTIONS.md` in the order given.
- A new game gets a new folder with its own `index.html` and `INSTRUCTIONS.md`.

## How to explain things

- Explain one thing at a time, clearly and concisely.
- Give the most important point first, then stop and let the user ask for the next one.
